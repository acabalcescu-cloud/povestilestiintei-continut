# Arhiva „Legendele Științei”

Arhiva istorică a Universității Craiova, pe 8 epoci (1948–2026).

- `epoci.json` – textele fiecărei epoci: introducere, momente, loturi istorice, surse.
- `legende.json` – fișele jucătorilor pe epoci (perioada la Craiova, meciuri, goluri, selecții, text).
- `surse/` – datele brute folosite: paginile Wikipedia (ro/en), textele de pe ucv1948.ro (Legende, Istoric, Palmares), scripturile de extragere.

Reguli: fiecare cifră din fișe trebuie confirmată de două surse (Wikipedia ro + en, site-ul clubului, Labtof).
Unde sursele nu se potrivesc, cifra nu apare. Fără disputa de identitate.
