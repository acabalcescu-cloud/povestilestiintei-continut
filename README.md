# Poveștile Științei – conținut automat

Cronicile și scorurile meciurilor Universității Craiova pentru [povestilestiintei.ro](https://povestilestiintei.ro).

- `cronici/` – cronica (JSON), coperta (JPG) și datele copertei, câte una pe meci.
- `index.json` – lista cronicilor pe care site-ul le preia (la 15 minute, ca ciorne).
- `STIL.md` – vocea blogului. `INSTRUCTIUNI.md` – pașii sesiunii care scrie cronica după meci.
- `unelte/coperta.js` – generatorul de coperte (Playwright). Fonturi: Sofia Sans Extra Condensed (OFL).
